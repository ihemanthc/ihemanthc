## About

I am a Full Stack AI Engineer at Estuate, Inc., based in Bengaluru, India. I design and ship AI systems end to end, from the data and retrieval layer to the API and the user interface. My work centers on production grade Retrieval Augmented Generation platforms, multi agent workflows, and the operational side of LLM applications: reliability, observability, evaluation, and cost control.

I care about building AI features that behave well outside a demo. That means clear architecture, tested failure paths, measurable quality, and systems that a team can run and maintain.

      <h3><a href="https://github.com/ihemanthc/tollgate">Tollgate: Calibrated LLM Cost Router</a></h3>
      <p>Routes each LLM query to the cheapest model tier that answers it acceptably. A fine tuned Laya encoder predicts the minimum sufficient tier (local small, mid tier, or frontier) with calibrated confidence, and low confidence queries escalate to a stronger tier. Labels come from an LLM judge comparing every tier against the frontier answer, and the routing threshold is fixed on a separate calibration split before final testing.</p>
      <p>
        On a 60 query held out test split from a 300 query dataset, the router reached 88.3% tier accuracy, retained 91% of frontier quality at roughly 3.6 times lower cost, and temperature scaling reduced calibration error from 0.142 to 0.031. Router latency measured 124 ms at p50 on CPU.
      </p>
